# R3.24 H1 Candidate Discovery

R3.24 is intentionally **one large stage**, not R3.24A/B/C micro-stages. The same command performs discovery, sensitivity/robustness analysis, integrated audit, and the single final seal.

Run from the WorldSim root:

```powershell
.\run_v0_6D1_R3_24.ps1
```

Required parent: `v0.6D1-R3.23` SEALED 48/48.

Outputs:

- `outputs\v0_6D1_R3_24` — H1 criteria, all-species diagnostics, 12-lineage shortlist, sensitivity analysis, arrays, audit and manifest.
- `outputs\v0_6D1_R3_24_SEAL` — the one final R3.24 seal.

The shortlist is a follow-up priority list for H2 detailed biology, **not** a declaration that any lineage is human and not an extant-Homo similarity ranking.
