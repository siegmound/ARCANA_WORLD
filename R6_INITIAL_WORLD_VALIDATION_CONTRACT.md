# R6 Initial World Validation Contract

**Status:** Validation design only; no scientific output was generated or checked.
**Scope:** Validate a future single 210 Ma R6 synthetic initial-geography package against the paired specification and generator contract.

## Fail-closed input identity

The future materializer first verifies repository/baseline identity, parses the authority chain, verifies the A1 reference hash, and confirms that A1 remains reference-only. Protected execution-index staged blobs must be inspected by blob identity before and after; no index working-tree content is to be staged or rewritten. A mismatch blocks materialization rather than silently rebasing the contract.

## Grid and morphology

Verify exactly 180×360 cells, canonical coordinates, periodic longitude, explicit polar adjacency, and spherical cell areas using the specified radius. The summed area must equal `4πR²` within relative tolerance `1e-10`. Compute land/ocean fractions and supercontinent metrics with these area weights, not raw cell counts. Connected-component logic must handle the spherical seam and poles identically in production and tests. All morphology bounds are authorial design acceptance criteria—not paleogeographic observations or fits.

## Fields and UNKNOWN

Check every supported land elevation is finite and in [0, 8,000] m relative to the R6 datum and carries the `AUTHORIAL_SYNTHETIC_INITIALIZATION` classification. Elevation is not populated on ocean-mask cells in v1. Ocean bathymetry and plate motion remain UNKNOWN; no zero defaults are accepted. Deep, climate, hydrology, biology, soil, and resource fields are not generated by this initial-geography materializer. For every field, verify units, native grid, time support, support class, authority class, uncertainty, method/source ID, and hash.

## Time, causality, and determinism

The package contains exactly one initial state at exactly 210 Ma. The check suite rejects backcasting, interpolation, endpoint fitting, or use of A1/R1–R3 numeric frames as an initializer/target. Determinism is evaluated in a clean process using the named R6 streams and pinned runtime; compare canonical payload bytes/hashes. Benchmark peak memory and wall time on the specified workstation class. Do not claim performance until measured.

## Governance and result

An UNKNOWN mask is a valid state and yields `PASS_WITH_UNKNOWN` when all required design invariants pass. Any missing mandatory field support, fabricated ocean depth/plate velocity/Deep value, failed geometry bound, hash mismatch, non-deterministic output, or prohibited mutation returns BLOCKED/FAIL with the exact reason. Validation itself must not execute physical evolution, climate, hydrology, Deep, soil, biology, or later resource stages. It must not update current state, the authority register, or execution indexes.
