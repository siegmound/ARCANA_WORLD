# ARCANA World 1 — v0.6D1-R3.7D

R3.7D closes the real repaired NEMO selection evidence and adds a fail-closed adaptive-selection shadow envelope.

Main result: do not use the parent `S_selected-S_neutral` quantity as the squared adaptive distance. R3.7D computes the matched allele-frequency displacement first and then its segregation norm. This restores `K<=64` and reveals a stable N=2000 dynamic-selection participation band (~37.61–41.00, median ~38.47), while N=500 remains strongly finite-N sensitive.

This stage does not authorize a production scalar K or a production runtime replacement.
