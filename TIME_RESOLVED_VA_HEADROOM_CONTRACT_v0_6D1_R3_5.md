# v0.6D1-R3.5 — Time-Resolved VA Headroom Contract

## Purpose
R3.4 showed that a frozen 150 Ma endpoint relaxes below `q=0.08`, but the full 210→150 Ma replay still contacts `q=0.08` transiently. R3.5 therefore measures the **dynamic path** of normalized additive variance rather than changing homeostasis again.

## Scientific locks
R3.5 does **not** modify:
- mutation supply `mu = 0.002 q/Myr`;
- nonlinear homeostasis `b = 0.9876543209876544 / Myr / q`;
- no-flow equilibrium `q*=0.045`;
- D3.2C barrier history;
- D3.2B barrier-coupled migration/contact;
- current-species-bound gene flow;
- fission/coalescence/speciation/extinction semantics;
- biology cadence 125 kyr or transport cadence 62.5 kyr.

The only sensitivity variable is the pre-existing **safety ceiling**: primary runs `q_cap=0.08` and `q_cap=0.10`.

## Non-invasive instrumentation
The scientific trajectory is still generated by the exact R3.4 runtime. R3.5 temporarily wraps the already-used D3.3A functions:
1. `gene_flow_moment_mix` — records `VA` immediately before gene flow;
2. `advance_nonflow_variance` — records the state after gene flow and the exact parent result after Riccati homeostasis.

A second **diagnostic-only** call to the same D3.3A Riccati operator uses a very high cap to estimate the unclipped result. It is never fed back into the simulated state.

This allows each 125 kyr biology step to record:
- max/median/P95/P99 `q` before gene flow;
- max `q` after gene flow;
- max `q` after unclipped homeostasis;
- max `q` after actual homeostasis;
- number/fraction of reservoirs that required clipping;
- number/fraction ≥99% of the configured safety ceiling;
- per-axis maxima (thermal/aridity/body);
- root lineages/axes at or near the ceiling;
- fission/coalescence/speciation/remap events occurring in the same biology step.

## Dynamic sensitivity protocol
Run the same R1 common state with identical seed and all identical parameters:
- H0.08: `q_cap=0.08`;
- H0.10: `q_cap=0.10`.

### Interpretation
- If 0.10 is non-binding over the full dynamic replay (`0` clipping steps and `0` steps ≥99% cap), it is a valid headroom candidate.
- If 0.10 also clips repeatedly, do **not** raise the cap again by default; reopen homeostasis/admixture calibration.
- Differences between H0.08 and H0.10 in speciation timing/identity must be treated as evidence that 0.08 was dynamically active, not as an error by itself.
- A final production ceiling should be confirmed to be non-binding over the full dynamic replay and, if needed, by one additional higher-headroom confirmation (e.g. 0.12) rather than chosen from a frozen endpoint alone.

## Promotion gate for 150 Ma
150 Ma can be promoted only after the dynamic telemetry establishes that the chosen production safety ceiling is non-binding and the resulting macrohistory passes the ordinary population, moment-conservation, fission/coalescence, speciation and micro-deme audits.
