# v0.6D1-R4.25 — Target Protocol Repair Execution Preflight & Geonomics J14 Spatial Authority Discovery

## Purpose
R4.25 consumes the SEALED R4.24 closure. It performs two read-only operations: (1) preflight all 57 active ARCANA target-repair records for a later implementation stage, and (2) search existing R3 canonical evidence for an explicit, exact-3 Ma spatial authority that could support frozen Geonomics J14 without synthesizing coordinates.

## Governance
- No external engine execution.
- No numeric target materialization or adjudicative promotion.
- No readjudication.
- No canonical replay or parameter change.
- Deep biological coupling remains OFF.
- External-engine outputs may never define ARCANA target values.
- R4.2 J14 is immutable.
- R3.27 scalar `deme_count`/macro state cannot be converted into spatial coordinates.
- Backward interpolation from 250 ka / 200 ka is forbidden without explicit prior authority.

## Target preflight
All 59 R4.20 records receive a disposition. The 57 active records are separated into executable read-only canonical extractor implementations, rejection-cause-only semantic repair audits, target-design authority requirements, or source/authority deferrals. The 2 context-only proxy records remain nonadjudicative.

An extractor is preflight-ready only when at least one present source survives the canonical-authority screen and has a supported read-only format. R3 external-engine artifacts are excluded even when R4.17 listed them as candidate hits.

## J14 discovery
Discovery re-audits R4.23's known J14 sources and performs a bounded read-only search of R3/reference artifacts. An existing authority can be accepted only if the same artifact contains explicit spatial support, an exact 3 Ma time authority, time-indexed spatial state/support, and separately verifiable SEALED R3 provenance.

If none is found, R4.25 does not create a replay. It freezes a R4.26 request path for a new engine-independent canonical spatial authority. If one is found, R4.26 must still validate/materialize the binding before any Geonomics execution is authorized.
