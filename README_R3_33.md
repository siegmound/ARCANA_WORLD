# R3.33

Single-stage overlay for Holocene environmental-resource coupling, H0 animal ecological-partner screening, domestication trajectories and food-production emergence.

Run on the consolidated/local WorldSim root after R3.32 is SEALED:

```powershell
.\run_v0_6D1_R3_33.ps1
```

R3.33 does **not** invent plant species. Agriculture remains blocked until an explicit producer/flora authority exists.
