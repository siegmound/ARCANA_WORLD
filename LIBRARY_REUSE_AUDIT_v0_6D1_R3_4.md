# R3.4 Library / Authority Reuse Audit

R3.4 introduces no new scientific dependency.

Reused authorities:
- NumPy for array/state algebra.
- SciPy infrastructure already inherited by the rebased runtime.
- D3.2B permeability-aware pair geometry.
- D3 dynamic-deme semantic rule that gene flow is grouped by current species identity.
- D3.3A moment-conserving gene-flow mixer, 45% aggregate exchange safeguard, Riccati variance homeostasis, mutation supply and nonlinear depletion coefficient.

Rejected changes:
- no new homeostasis law;
- no arbitrary increase of `b`;
- no genome-level msprime/tskit rewrite;
- no new admixture rate or global speciation/extinction rate.

New code is limited to rebased-runtime glue, current-species metadata aliasing, headroom audit instrumentation, and package/run scripts.
