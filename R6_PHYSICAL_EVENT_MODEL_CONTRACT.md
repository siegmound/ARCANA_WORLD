# R6 physical event model contract

**Status:** event envelope and causal guards frozen; event laws remain unbound.

Every discrete physical change is an immutable ARCANA-owned event produced by an authorized law. An event requires a state/driver precondition, causal trigger, explicit semantic pre/post state, validation and provenance. A random timestamp alone is not a trigger. Seeded stochasticity can only resolve a choice under an authorized physical eligibility rule and distribution. Unknown eligibility remains unknown.

The event envelope carries event ID/type/time convention, spatial support, participating plates, pre/post state IDs and hashes, law/version, parameter-set ID, seed lineage where consumed, uncertainty, source/support/provenance, solver diagnostics and validation result. Candidate events are rift initiation, plate split, boundary-class change, optional subduction initiation, collision start/end, orogenic episode start/end, major uplift/subsidence summaries and topology reconnection. This vocabulary does not assert that any event has occurred or is executable.

A split requires a parent ID, stable child IDs, split event/time/geometry, pre/post states, new boundaries and child-kinematic authority. Parent identity remains queryable before the split; no retroactive reassignment. No event is not implicit persistence: persistence needs an explicit time-valid law.

Existing CHA transformations may be inserted between physical states only at their independently authorized boundaries. No tectonic effect is inferred for an event whose contract does not provide one. Manual map editing, untriggered stochastic events, solver-authored laws, lineage changes without events, and events without pre/post provenance are prohibited. No physical evolution is authorized by this contract.
