# v0.6D1-R3.7B — Directional Selection Participation Calibration Gate

R3.7A defined

`dh = dz / sqrt(2 K_eff)`

as the minimum-distance trait-aligned mapping from an already-authorized heritable trait response to latent adaptive genetic displacement.

The parent 64-QTL reference gives a static participation range of approximately 46.65–63.50, median ~59.62. That is useful architectural evidence but not a dynamic production calibration.

The R3.7A B2 run cannot close this gate because:
- NEMO selection was disabled;
- mutation was disabled;
- all divergence in B2 is drift + connectivity history.

Therefore R3.7B explicitly refuses to promote 59.62, 64, or any fitted scalar to World-1 authority.

## Required next oracle
A dedicated NEMO directional-selection chain must contain at least:
1. common connected/burn-in start;
2. isolated demes with controlled, divergent trait optima or equivalent NEMO quantitative-trait selection;
3. direct observation of trait-mean response `dz` and allele-frequency-derived `S` through time;
4. matched neutral controls;
5. at least N=500 and N=2000 and multiple replicates;
6. reconnection phase to test whether adaptive and neutral components transform coherently.

Only that experiment can authorize a World-1 `K_eff` rule or establish that a scalar `K_eff` is insufficient.
