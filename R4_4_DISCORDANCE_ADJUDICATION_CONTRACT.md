# ARCANA WorldSim v0.6D1-R4.4 — Discordance Adjudication Contract

R4.4 consumes the SEALED R4.3 evidence bundles. It does not run an external engine and does not modify ARCANA canonical state.

## Governing rules

- Exactly the R4.3/R4.2 frozen windows, jobs, domains and domain authorities are inherited.
- The five frozen scientific classes are: `CONCORDANT`, `CALIBRATION_OFFSET`, `STRUCTURAL_DISAGREEMENT`, `SEMANTICALLY_NONCOMPARABLE`, `INSUFFICIENT_EVIDENCE`.
- No majority vote is allowed. PRIMARY evidence is adjudicative; SECONDARY evidence is context only.
- `PROXY_ONLY` evidence cannot by itself create a structural-disagreement finding or promote global scientific agreement.
- A crash or adapter problem cannot become scientific disagreement; R4.3 must already be SEALED with zero blocked jobs.
- R4.3 compressed representative-response experiments are not literal multi-Myr replays. R4.4 therefore privileges response direction and only uses effect magnitude as a calibration diagnostic where a NORMALIZABLE target/metric pair exists.
- Missing normalized result metrics or missing ARCANA outcome semantics are preserved as `INSUFFICIENT_EVIDENCE` rather than inferred.
- R4.4 may nominate an earliest affected authority candidate for a robust structural disagreement, but may not alter parameters, execute a replay, or promote external evidence into canonical state.

## Domain resolution

Within one window/domain, PRIMARY evidence is resolved by fail-safe severity precedence:

`STRUCTURAL_DISAGREEMENT > CALIBRATION_OFFSET > CONCORDANT`.

This is not engine voting: a single authoritative structural disagreement cannot be outvoted by multiple concordant engines. If no primary NORMALIZABLE result/target pair exists, the result is semantic noncomparability or insufficient evidence.

## Downstream

R4.5 is selected from the observed evidence topology:

- structural disagreement -> causal diagnosis + earliest-authority recalibration/replay plan;
- evidence gaps/noncomparability -> targeted adapter/evidence-gap closure;
- calibration offsets only -> targeted calibration review without automatic canonical change;
- complete concordance -> revalidation-closure/baseline-promotion gate.
