# HRAB AA-aware provider architecture adjudication

## Result

`GUM_AA_AGE_CLASS_AUTHORITY_RECOVERED__TARGETED_COMPLETION_REFINEMENT_PERSISTENCE_AND_REMOVAL_REMAIN_REQUIRED`

GUM is retained as the existing bound base authority for material identity, native spatial support, and broad sediment age classes where `AA` is populated. It is not an exact event, persistence, removal/reworking, or continuous temporal-history authority.

The 4,602 known-material ARCANA cells contain 1,980 HRAB-relevant GUM age-class constraints, 1,653 broad/not-localizable age classes, 49 predominantly outside/not-localizable classes, and 900 explicit `nn` unknowns. These counts are evidence categories from the corrective matrix; refinement and persistence requirements are overlapping overlays, not additional mutually exclusive cell partitions.

## Provider revision

The previous provider architecture is **SUPERSEDED / PARTIALLY REVISED**. External providers are no longer needed as a universal first-order age source. Their justified roles are targeted age completion, age/event/formation refinement, domain-specific chronology, shoreline or marine spatial completion, and event-specific persistence/removal evidence.

OCTOPUS is prioritized for dated depositional-landform and event refinement; NCEI loess/paleosol, NCEI Lake, and C-PEAT remain matched-site or core chronology authorities; regional glacial sources remain ice-margin/deglaciation event authorities; Smithsonian GVP remains event-specific; none automatically replaces valid GUM `AA` classes.
