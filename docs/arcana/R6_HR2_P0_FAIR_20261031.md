## First minimal physical domain and validation gate

Candidate: **closed-sphere conservative mobile-cover diffusion**, extending the
existing two-support cover-transfer law only through a separately authorized
implementation. Current status: REQUIRES_NEW_IMPLEMENTATION plus
BOUNDARY/INPUT_MISSING for an R6 source-backed global scenario. No runnable
six-grid candidate is claimed in this audit.

Use h[m], V=A*h[m3], M=rho*V[kg] and a declared diffusivity kappa[m2/year].
The proposed equation is d h/dt=kappa*Laplace_Beltrami(h). For each true shared
face once, F_ij=kappa*L_ij/d_ij*(h_i-h_j), equal/opposite volume transfer;
simultaneous updates from one old-time state. Fixed flat bedrock, closed sphere,
uniform density and no external sources are explicit **verification scenario**
choices, not retrospective claims of zero natural forcing or known regolith.
The current pair's limiter is not a multi-neighbor CFL or positivity proof.

The [minimum-physics plan](../../../ARCANA_WORLD_EVIDENCE/R6/HR2_P0_20261031_01/MINIMUM_PHYSICS_AND_VALIDATION.md) specifies
positive areas, periodic seam, zero-length outer polar faces, no flux across
topological point contacts, and explicit positivity/stability
dt<=0.5*min(A_i/sum_j c_ij). Smaller polar cells can require subannual timesteps;
one-year output cadence must not force a one-year solver step. Record actual
substeps and boundary/source/flux budgets. No arbitrary application resource cap.

Proposed next bounded tests, **not run here**:

1. Ratify coefficient/initial-condition/mesh/input identities and verification
   scope. A manufactured analytic field is openly a model test, never observed
   ARCANA data or nine-cell replication.
2. Independent rational2×2 **local patch** oracle, not a2:1 global raster:
   unequal areas, exact internal flux signs, zero flux, positivity and bad-dt
   rejection.
3. A16×8 sphere with a constant field and positive degree-one spherical harmonic,
   exact cell-average continuum decay exp(-2*kappa*t/R2), seam/pole checks,
   every-step volume/mass closure and a pre-derived binary64 accumulation budget.
4. Mesh16×8→32×16→64×32→128×64→256×128 and dt→dt/2→dt/4 at fixed physical time;
   retain weighted L1/L2/Linf, phase/amplitude and all residuals. Proposed criteria
   include first-order temporal behavior and spatial order>=1.5 in the resolved
   range, fixed before execution. Failure requires diagnosis, not tolerance tuning.
5. Separate-process native restart, short direct/split3Y/10Y at identical planned
   configuration, complete state/event/material/clock parity and corruption
   negatives. Cross-grid validation uses convergence, not false byte equality.

Global authored topography exists, but mobile-cover thickness, density,
