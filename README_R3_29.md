# R3.29 — Population, Mobility, Settlement & Cultural Preconditions

Extract as an overlay on the current WorldSim root and run:

```powershell
.\run_v0_6D1_R3_29.ps1
```

The command validates source authority, runs regression, computes the 50→0 ka community/cultural-precondition layer and then performs one final seal audit. It does **not** create languages, religions, agriculture, cities or a final human identity.
