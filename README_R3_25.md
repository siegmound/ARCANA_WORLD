# R3.25 H2 Detailed Candidate Biology

R3.25 is one large stage. Run from the WorldSim root:

```powershell
.\run_v0_6D1_R3_25.ps1
```

Required parent: `v0.6D1-R3.24` SEALED 31/31.

Outputs:

- `outputs\v0_6D1_R3_25` — 12 detailed candidate dossiers, coupled-biology arrays, six embodiment-hypothesis envelopes, H2 sensitivity/robustness, and 6-lineage H3 priority cohort.
- `outputs\v0_6D1_R3_25_SEAL` — the single final R3.25 seal.

The H3 cohort is a resource-prioritized follow-up set, **not** a declaration that the six are human or that the other six are biologically impossible.
