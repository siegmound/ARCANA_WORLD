# ARCANA WorldSim v0.6D1-R4.28 Contract

## Purpose
R4.28 converts the R4.27 authority adjudications into **pre-result implementation preflights**. It does not execute target values, canonical replay, external engines, or readjudication.

## Target selector authority
For each of the 44 static-valid canonical extractors, R4.28 freezes an authority-definition packet containing the hash-bound canonical source, parser family, exact schema inventory, R4.16 domain protocol, and an explicit-selector-only rule. R4.28 does **not** choose a selector automatically. An exact selector can only be frozen by a later authority stage and must be one of the exact schema entries already recorded here.

Forbidden: fuzzy matching, synonym fallback, filename inference, result-selected selectors, and external-engine results defining ARCANA targets.

## Target design authority
The 12 R4.27-approved authority requests are implemented as nonnumeric pre-result scientific definitions. Their scientific constructs, canonical observables, unit families, temporal/spatial governance, uncertainty/aggregation requirements, forbidden shortcuts, and provenance requirements are preserved verbatim. Numeric materialization remains unauthorized.

## Semantic repair
The single R4.27-authorized review remains limited to the frozen rejection cause (`eligible_primary_row_count`). Target value change, mapping-class upgrade, and readjudication remain unauthorized.

## Geonomics J14
R4.28 builds the implementation preflight for a new engine-independent canonical spatial replay authority covering 3 Ma→200 ka. It requires explicit time-indexed spatial state, canonical paleogeographic/environmental provenance, R3.27 macro-invariant audit, hash-bound provenance, a new namespace, and sealing before any Geonomics use.

R4.28 does not authorize or execute the replay and does not mutate R4.2/J14.


## R4.28-R1 repair amendment
A hash-valid/static-valid source is not required to expose a named exact selector inventory. Empty exact inventories are preserved as explicit nonadjudicative deferrals; selector names may not be synthesized. Seal requires complete 44-record terminal accounting and zero blocked integrity records, not 44/44 ready selectors.
