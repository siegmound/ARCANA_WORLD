# v0.6D — Historical Deep Coupling Bridge Contract

Status: `PASS_HISTORICAL_BRIDGE_MECHANICS_D2_LINEAGE_INHERITANCE_CHA1_PULSE_AND_REAL_D22_TO_D3_TRANSFER_CANDIDATE__EXECUTABLE_D1_D2_RUNTIME_BINDING_PENDING`

## Purpose

v0.6D closes the representation boundary for a future historical Deep-coupled replay without pretending that D3 existed at 210 Ma. The authoritative biological chain is:

`D1 @ 210 Ma -> D2 pre-CHA1 -> D2.2 CHA-1 -> D3 post-CHA1`.

The Deep state is a sidecar. Biological representation may change, but the physical Deep ledger does not reset.

## Historical state

At D1/D2 resolution the sidecar is keyed by biological lineage/species ID and carries:

- `Z_X[species,10]` latent Deep mean;
- `V_A^X[species,10]` additive variance;
- acclimatization;
- remodeling;
- recoverable load;
- injury.

D1 identities are bound to the real 120-species metadata. Mean initialization is neutral (`Z_X=0`), but v0.6D intentionally refuses to invent a D1 standing-variance constant: production initialization requires the real/authorized D1-D2 variance state.

## Population -> passive Deep pressure

The v0.6A operator is representation-neutral and is reused on D1/D2 species rasters:

`population[species,y,x] + guild + Z_X -> dimensionless passive-acceptance pressure`.

`reference_population` remains only an abundance/opportunity normalization anchor. It is never `K`, never a physical individual count, and never multiplied by a Joule-per-individual constant. Rescaling both WorldSim population and the reference anchor by the same unit factor leaves saturation invariant.

## D2 lineage events

Deep has no lineage-birth authority. A new sidecar lineage may appear only after an explicit D2 speciation/branch event supplies parent and daughter IDs. The daughter inherits the parent's Deep first/second moments and physiology at recognition. Extinct lineages may disappear only because the D2 biological registry no longer contains them.

The real pre-CHA1 D2 event `HSG_003 -> HSG_025` is therefore representable without treating `HSG_025` as a Deep-created lineage.

## Heritable evolution during D1/D2

The v0.6B quantitative-genetic operators are reusable at species resolution:

- direction of `Z_X` comes only from the local gradient of population-weighted log viability;
- mutation contributes variance only, with zero mean shift;
- D3.3A long-horizon variance homeostasis is retained;
- drift individual-equivalent calibration remains in the genetics domain only, never the energy ledger;
- generation-time/reproduction inputs must be explicit; v0.6D does not infer them from WorldSim population units.

## D2.2 -> D3 bridge

The real D3.0A reference establishes:

- 31 D2.2 survivor species;
- 115 D3 derived deme seeds;
- no D3.0A speciation;
- no adaptive radiation;
- no trait evolution;
- no Deep authority in the parent bridge.

v0.6D clones each survivor's Deep moments and physiology into every D3-authorized seed belonging to that species. It does not create seeds or species.

The physical Deep state is copied unchanged across this representation transition:

`background + photo + source buffer + cumulative uptake/return/sink/stellar ledgers` remain one continuous state.

## HSG_025 provenance

`HSG_025` is a genuine D2 daughter of `HSG_003`, but the mounted R2 D3 bridge contains only an explicit ordinary-trait parent proxy because D2 did not export the evolved child trait vector. v0.6D therefore permits an explicit `HSG_003 -> HSG_025` **structural proxy** only for bridge-mechanics verification and labels it `NOT_HISTORICAL_DEEP_STATE`.

A production HX must obtain the actual HSG_025 Deep state by executing/binding the D2 lineage history, not by using the proxy.
