# R6 Targeted Physical-Evolution Research Questions

These are decision questions, not authority to acquire a provider or run a solver. ARCANA remains owner of canonical semantics; any external engine is only a bounded computation adapter.

1. **Minimum synthetic plate law:** For an Earth-scale spherical world initialized with one dominant supercontinent and a designed coarse plate/province partition, what is the least-complex defensible forward kinematic/process model that can represent rigid/semi-rigid plates, deterministic motion, rifting, collision, and boundary transitions without asserting real-Earth paleogeography? Compare Euler-pole rigid plates, spherical velocity fields, and process-constrained procedural event models; specify what each cannot represent.
2. **Breakup and collision causality:** What state and forcing are minimally necessary to initiate and propagate rifts and later collisions in a synthetic world? Which event timing/location features can be seeded and reproducible without arbitrary map authoring, and what physical bounds constrain them?
3. **Topographic response coupling:** What minimum laws couple extension/convergence to subsidence/uplift/orogeny, and at what scale can a global base model represent these while leaving kilometer-scale landscape evolution regional? State mass/area accounting and stability checks.
4. **Shoreline and ocean boundary:** Is land elevation plus a declared time-varying sea-level datum adequate for first continental evolution, and exactly when do shelf/bathymetry/ocean-volume fields become necessary? Define constraints without fabricating R6 t0 bathymetry.
5. **Landscape solver suitability:** Does a candidate such as FastScape solve a necessary R6 process (and at which scale), what inputs/boundary conditions/restart state does it require, and can its outputs be embedded as bounded evidence without owning ARCANA semantics? No tool is selected by this question.
6. **Deep coupling:** Is any canonical ARCANA Deep state/law physically coupled to mantle/tectonic forcing, or is such coupling an optional model choice? If coupled, define the minimum physical initializer, causal variables, units, conservation/energy accounting, and validation needed; do not infer this from the biological Deep contracts.
7. **Temporal integration and uncertainty:** What physically meaningful event boundaries, displacement/error limits, stability conditions, and ensemble-variable distributions are justified over 210 Myr? Establish checkpoint/restart completeness separately from historical snapshot requirements.

Resolution of these questions should support a later authority matrix and solver-suitability gate. No first interval is yet specified because motion, breakup, event, forcing, and topographic-response laws remain unbound.
