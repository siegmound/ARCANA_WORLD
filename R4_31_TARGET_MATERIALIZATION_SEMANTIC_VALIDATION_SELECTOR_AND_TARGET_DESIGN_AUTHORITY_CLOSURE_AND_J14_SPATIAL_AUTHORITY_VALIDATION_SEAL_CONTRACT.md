# ARCANA WorldSim v0.6D1-R4.31 contract

## Scope
R4.31 consumes the SEALED R4.30-R2 evidence only. It performs no external-engine execution, no new numeric-target extraction, no matrix readjudication, and no canonical state rewrite.

It has four independent duties:

1. **R4.30 target-attempt semantic disposition validation** — all five R4.29-authorized selector attempts must remain terminal. Materialized values, if any, are only semantic-validation candidates and cannot become adjudicative in R4.31. Deferred attempts are frozen into explicit authority-gap classes; no selector/source/transform is inferred after the result.
2. **57-record target-authority closure accounting** — the 5 authorized-selector attempts, 39 selector-rule gaps, 12 validated target-design definitions, and 1 primary-mapping repair gap must reconcile exactly to the 57 active target-protocol repairs. R4.31 may authorize only later *authority implementation*, never numeric target materialization.
3. **J14 independent validation seal** — independently revalidate the R4.30 3 Ma→200 ka spatial-authority candidate, recheck its frozen inputs and invariants, and deterministically recompute the pre-result algorithm in memory. If all checks pass, seal it as a **derived canonical spatial authority for external-revalidation binding**. This does not claim observed historical locations and does not rewrite the underlying canonical simulation state.
4. **R4.32 plan freeze** — if the J14 authority is sealed, R4.32 may materialize and statically validate Geonomics parameter bindings using J14/J18/J21 authority. Geonomics execution itself remains forbidden until a later explicit authorization.
