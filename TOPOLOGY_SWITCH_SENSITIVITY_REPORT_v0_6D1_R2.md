# Topology-Switch Sensitivity — v0.6D1-R2

The 210→180 Ma pilot uses a discrete support transition at 195 Ma. To test whether this midpoint is steering the macroevolution, the switch was shifted ±2.5 Myr using otherwise identical pilot settings.

| switch | final population | species-weighted L1 vs 195 | species P90 relative delta | species max relative delta |
|---:|---:|---:|---:|---:|
| 192.5 Ma | 1843.084057068 | 0.2879% | 0.8977% | 3.4828% |
| 195.0 Ma | 1843.084819169 | 0 | 0 | 0 |
| 197.5 Ma | 1843.085877280 | 0.2105% | 0.8941% | 2.9082% |

All cases retain 120 species. The midpoint is therefore retained as a **candidate representation choice**, not promoted to a geological event or canon catastrophe.
