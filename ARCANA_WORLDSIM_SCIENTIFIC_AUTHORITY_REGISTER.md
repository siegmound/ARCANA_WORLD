# ARCANA WorldSim Scientific Authority Register

Governed cross-cutting authority inventory. It records only evidenced state and its semantic ceiling; it does not create science.

## Mandatory gate

1. Before declaring a scientific authority absent, consult this register.
2. Inspect registered producer/provenance and respect its semantic ceiling.
3. Perform targeted recovery only when the relevant entry is UNRESOLVED.
4. Do not infer absence from ARCANA_WORLD_CURRENT_STATE.md alone.
